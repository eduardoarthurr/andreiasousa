# Landing Page para Advogada

Este projeto consiste em uma landing page desenvolvida para uma advogada, criada como um trabalho freelancer.

## Sobre o projeto

Esta foi minha primeira experiência desenvolvendo um site para um cliente real. O objetivo foi criar uma página simples, moderna e funcional para apresentar os serviços da advogada e facilitar o contato com potenciais clientes.

## Tecnologias utilizadas

* **HTML** — Estrutura da página
* **CSS** — Estilização e design responsivo
* **JavaScript** — Interatividade básica
* **Bootstrap** — Framework para facilitar o layout responsivo e componentes visuais

## Funcionalidades

* Layout responsivo para dispositivos móveis e desktops
* Seções claras para apresentar serviços, informações e formulário de contato
* Design simples e profissional, adequado para o perfil da advogada

## Como usar

1. Clone este repositório:

   ```bash
   git clone <URL do repositório>
   ```
2. Abra o arquivo `index.html` no seu navegador preferido para visualizar a landing page.

## Considerações finais

Foi uma ótima oportunidade para aplicar conhecimentos de front-end e entender melhor as necessidades de um cliente real. Pretendo continuar aprimorando minhas habilidades e desenvolvendo projetos cada vez mais completos.
